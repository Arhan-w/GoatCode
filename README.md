# GoatCode

GoatCode is a terminal AI agent that helps with coding tasks, featuring a smooth web interface with Jarvis-style 3D HUD.

## Features

- **Web Interface**: Run `bun run start:web` for a cinematic 3D experience
- **Update Checker**: Stay current with `check-update` command
- **Desktop Control**: Full computer interaction capabilities
- **Task Management**: Structured todo system for complex workflows

## Demo Videos

Check out our [demo videos](docs/videos.md) showing:
- Web interface overview
- Update check feature

## Installation

```
bun install -g @goated/goatcode
```

## Usage

```
goat -p "Build a React component"
```

## Development

```
bun run dev
```
