# Brag Plan: GoatCode v3

## What is this app?
GoatCode v3 is a major architectural leap designed for professional developers who demand complete control, sub-second code intelligence, and team collaboration without leaving their terminal. Powered by Bun and TypeScript, GoatCode combines **180+ LLM providers** (with intelligent fallback chains and Anthropic prompt caching) with four brand-new pillars: Multi-Repo Workspaces (`workspace.repos`) — Mount multiple repositories simultaneously, run cross-repo searches (`/find`, `/index`), and enforce per-repo sandboxes and strict permission rule forms; Code Intelligence Graph (`src/code`) — Zero-config tree-sitter parser with WASM fallback supporting TS, JS, Python, and Go. Incremental mtime+size fast path, atomic persistence, and TF-IDF ranked symbol lookup; P2P Collaboration Relay (`src/collab`) — End-to-end encrypted WebSocket relay with Lamport timestamp sequencing, invite codes, turn tokens, and live peer synchronization; Agent-as-a-Service Protocol (`src/protocol`) — JSON-RPC 2.0 over HTTP (`POST /rpc`) and WebSocket with constant-time token auth, path-jailed execution, and remote agent mounting (`remote_<name>`); Signed Plugin Marketplace (`src/plugins`) — Secure tar+gzip extractor with path-traversal/bomb guards and ed25519 signature verification against pinned keys. Plus Goated-Flash-Free — Zero-config built-in free tier: when no API key is connected, GoatCode auto-boots an embedded free inference engine, giving you full AI coding out of the box with zero setup.

## The angle
The autonomous multi-repo AI coding agent that gives you enterprise-grade code intelligence and real-time collaboration — all from your terminal with zero setup required. While other agents need API keys and complex configurations, GoatCode v3 works out of the box with its embedded free model, yet scales to enterprise needs with 180+ providers, P2P collaboration, and JSON-RPC agent protocols. It's the absurd idea of a truly free, fully-featured coding agent that actually works — delivered deadpan serious.
